1. В Termux на Android

Это самый простой способ. Откройте Termux и выполните команду для клонирования репозитория:

```bash
git clone https://github.com/Razehtml/py-MALTEGO-mobile.git
```

Затем перейдите в папку с проектом и запустите скрипт:

```bash
cd py-MALTEGO-mobile
python pyMALTEGOmobile.py
```

Если у вас не установлены зависимости, установите их перед запуском:

```bash
pip install requests dnspython python-whois
```

2. В Pydroid 3 на Android

Это приложение для запуска Python-кода на телефоне. Чтобы использовать инструмент в Pydroid:

1. На странице репозитория нажмите зеленую кнопку Code и выберите Download ZIP.
2. Распакуйте скачанный ZIP-архив на вашем устройстве.
3. Откройте Pydroid 3 и через меню "Open" выберите файл pyMALTEGOmobile.py из распакованной папки.
4. Нажмите кнопку "Run" (обычно это треугольник в правом верхнем углу).

Убедитесь, что в Pydroid установлены библиотеки requests, dnspython и python-whois. Их можно установить через встроенный менеджер пакетов Pip в самом приложении.

3. Альтернативный способ: скачать файл напрямую

Если у вас нет git, вы можете скачать единственный файл pyMALTEGOmobile.py прямо на странице репозитория. Нажмите на него, а затем на кнопку "Raw" в правом верхнем углу, чтобы сохранить его.

После этого поместите файл в любую папку на вашем устройстве и запустите его через Python.

Если при запуске возникнут ошибки, проверьте, что вы установили все необходимые библиотеки из пункта "Установка зависимостей". Код должен работать как в Termux, так и в Pydroid. Удачи
